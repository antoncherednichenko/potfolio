# Farm Portfolio

Основа будущего портфолио фронтенд-разработчика в виде фермы на Next.js + Phaser.
Сейчас на главной странице только пустой инстанс Phaser: чёрный canvas без сцен,
объектов, управления и интерфейса. Обычное резюме не входит в MVP.

## Запуск

Требуется Node.js 24 LTS и npm 11.

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000. Пустой чёрный экран — ожидаемое состояние каркаса.
Phaser загружается только в браузере и уничтожается при размонтировании страницы.

## Команды

| Команда                | Назначение                               |
| ---------------------- | ---------------------------------------- |
| `npm run dev`          | Локальная разработка                     |
| `npm run build`        | Production-сборка и проверка SSR         |
| `npm start`            | Запуск production-сборки                 |
| `npm run typecheck`    | TypeScript без генерации файлов          |
| `npm run lint`         | ESLint, включая границы импортов         |
| `npm test`             | Контракт контента и границы архитектуры  |
| `npm run test:watch`   | Тесты при изменениях                     |
| `npm run format:check` | Проверка форматирования                  |
| `npm run format`       | Форматирование исходников и документации |
| `npm run check`        | Типы, линтер, тесты и форматирование     |

GitHub Actions выполняет `npm ci`, `npm run check` и `npm run build`.


## Структура

```text
AGENTS.md                 инструкции для coding agents
docs/                     продукт, архитектура, контент, проверки, планы
src/app/                  layout и главная страница с lifecycle Phaser
src/content/              JSON, схема, типы и загрузчик
src/game/create-game.ts   фабрика пустого Phaser.Game
tests/                    проверки контента и границ импортов
public/                   место для будущих ассетов
```
