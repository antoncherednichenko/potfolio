# Проверка карты world.json

Проверено 26 октября 2026 года. Карта после ручного редактирования сохранена;
проверки генератора выполнялись в отдельной временной копии.

| Проверка                        | Результат                                                                                                                           |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Рекурсивный анализ ресурсов     | 23 PNG, 3 файла карты/редактора; размеры и SHA-256 в манифесте                                                                      |
| Структура Tiled                 | 50×50 тайлов по 16×16 px, 9 встроенных тайлсетов, 6 Tile Layers и 5 Object Layers                                                   |
| Ссылки и графика                | Все изображения найдены; 116 используемых GID корректны и не полностью прозрачны                                                    |
| Игровая разметка                | 39 прямоугольников коллизий, 5 интерактивных объектов, 1 NPC-маркер, 2 триггера, 1 старт                                            |
| Проходимость                    | Все 557 клеток дорог и 9 игровых целей доступны; 2097 свободных клеток, изолированных нет                                           |
| Сохранность исходников          | Все 23 PNG, `tile-map.json` и `.tiled-project` совпадают с исходными SHA-256                                                        |
| Нативный рендер Tiled 1.12.2    | Получен и визуально просмотрен `previews/WorldTiled.png`, 800×800 px                                                               |
| Экспорт Tiled JSON → TMX → JSON | CLI завершился без ошибок; тайлы и метаданные объектов сохранены; максимальное округление координат — 0,000334 px                   |
| Парсер Phaser 4.2.1             | Прочитал все тайловые и объектные слои без предупреждений                                                                           |
| Тесты генератора и валидатора   | `node --test scripts/maps/*.test.mjs`: 9 тестов прошли                                                                              |
| Воспроизводимость               | Два запуска генератора в изолированной копии дали одинаковые три JSON-файла; запрет перезаписи и сохранение ручных правок проверены |
| Проект                          | `npm run typecheck`, `npm run lint`, `npm run build` прошли                                                                         |
| Форматирование                  | Проверены новые скрипты, каталоги, отчёты и документация; сохранённый пользователем `world.json` не переформатировался              |
| Существующая команда `npm test` | Vitest завершился с кодом 1: в `tests/**/*.test.ts` нет тестов; тесты системы карт запускаются отдельной командой выше              |

В нативном рендере просмотрены дом, деревья, берег пруда, огород, заборы,
стыки дорожек и размещение препятствий. Разбитых многотайловых объектов или
перекрытых основных проходов не обнаружено. Сравнение CPU-рендера с Tiled дало
расхождение максимум на 1 уровень цветового канала у 9416 из 640000 пикселей.

Проверка проходимости консервативно закрывает любую клетку, пересекающую коллизию.
Она подтверждает маршруты между центрами клеток для тела 12×12 px. Прохождение
в браузере, физика, взаимодействия и анимации NPC в Phaser не проверялись:
карта пока не подключена к действующей сцене.

Служебный `tileMap.tiled-session` изменился во время работы с редактором/CLI.
Точный источник изменения по хешам установить нельзя; исходный хеш сохранён
в манифесте, текущий записан предупреждением в машинных отчётах. Графические
ресурсы и исходная карта не изменены.
