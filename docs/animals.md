# Животные

Подготовлены `chicken`, `cow`, `pig`, `sheep`. Игровая сцена создаёт пять овец
вокруг маркера `NPC/sheepSpawn` и задаёт им случайные цели внутри прямоугольника
`Areas/sheepArea`. При движении учитывается внутренний отступ размером в один
кадр, поэтому спрайты не выходят за пределы пастбища. Исходные PNG сохранены без
изменений.

Также игровая сцена создаёт пять куриц вокруг маркера `NPC/ChickenSpawn` и задаёт
им случайные цели внутри `Areas/chickenArea`.

У всех листов размер 64×64, сетка 2×2 с кадрами 32×32, без отступов и
промежутков. Нумерация слева направо, сверху вниз:

| Анимация | Кадры | Частота    | Повторение |
| -------- | ----- | ---------- | ---------- |
| `idle`   | 0, 1  | 2 кадра/с  | бесконечно |
| `walk`   | 2, 3  | 6 кадров/с | бесконечно |

В исходниках животные смотрят влево. Для взгляда вправо используется `flipX`.
Отдельных кадров для взгляда вверх и вниз в этих листах нет.

Коллизии — динамические прямоугольные тела Arcade Physics у ног. Координаты
отсчитываются от левого верхнего угла кадра, размеры указаны без масштабирования.
Симметричные по горизонтали тела не смещаются при развороте.

| Вид    | Смещение X, Y | Ширина × высота |
| ------ | ------------- | --------------- |
| Курица | 11, 19        | 10×4            |
| Корова | 7, 20         | 18×6            |
| Свинья | 7, 18         | 18×5            |
| Овца   | 8, 18         | 16×5            |

Гравитация отключена, границы физического мира учитываются. Игрок не толкает
животных (`pushable: false`), но они могут двигаться и останавливаться перед
препятствиями. Глубина обновляется по нижней границе тела после разрешения
коллизий, как у игрока.

Подключение животного вручную:

```ts
import { Animal } from '@/game/entities/animal';

// В preload():
Animal.preload(this);

// В create(), после настройки границ мира:
const cow = new Animal(this, 'cow', 160, 160);
cow.collideWith(player.sprite);
cow.collideWith(obstacles);

// Скорость в пикселях мира в секунду; ходьба и разворот переключатся сами.
cow.setVelocity(20, 0);
cow.stop();

// Для воспроизведения без движения:
cow.setFacing('right').play('walk');

// Удаляет спрайт, физическое тело, созданные через collideWith коллайдеры
// и обработчики сцены. Также выполняется при завершении сцены.
cow.destroy();
```

Анимации регистрируются один раз и переиспользуются экземплярами. Каждое животное
создаёт собственное физическое тело. Пары столкновений задаются явно через
`collideWith`: наличие тела само по себе не включает столкновения со всей сценой.
Для столкновения двух животных достаточно одной пары, например
`cow.collideWith(sheep.sprite)`.
